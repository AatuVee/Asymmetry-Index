# Asymmetry-Index
Asymmetry Index measures whether an asset moves faster up or down. It tracks consecutive price streaks and calculates SI (downside intensity), UI (upside intensity), Reactivity ((SI+UI)/2), and Asymmetry (UI/SI). Asymmetry >1.2 = upside-biased, &lt;0.8 = downside-biased. Best used on the Daily timeframe.
